# KonturSMM Landing

Статичный лендинг для Cloudflare Pages, GitHub Pages или любого хостинга без сборки.

## Что внутри

- `index.html` - основная страница с SEO-мета, Open Graph и JSON-LD.
- `articles/index.html` - страница списка статей.
- `articles/article-template.html` - готовый шаблон новой статьи; он закрыт от индексации, пока не заменён реальным материалом.
- `styles.css` - вся стилизация, светлая и тёмная темы, адаптив и анимации.
- `script.js` - переключение темы, мобильное меню, FAQ, плавные якоря, CTA-ссылки, фиксация UTM и цель для Яндекс.Метрики.
- `assets/` - SVG-логотипы, иллюстрация и OG-обложка.
- `robots.txt`, `sitemap.xml`, `404.html` - базовые файлы для публикации.

## Быстрый запуск

Откройте `index.html` в браузере или загрузите всю папку в репозиторий.

Для GitHub Pages:

1. Залейте содержимое папки в репозиторий.
2. Откройте Settings -> Pages.
3. Выберите ветку и папку `/root`.

Для Cloudflare Pages:

1. Создайте Pages-проект.
2. Подключите репозиторий.
3. Build command оставьте пустым.
4. Output directory укажите `/`.

## Что заменить перед запуском

В `script.js`:

```js
telegramBotUrl: 'https://t.me/KonturSmmAiBot',
metrikaCounterId: ''
```

- `telegramBotUrl` замените на реальную ссылку вашего Telegram-бота.
- `metrikaCounterId` заполните ID счетчика Яндекс.Метрики, если счетчик уже установлен на странице.

В `index.html`, `robots.txt` и `sitemap.xml` замените `https://kontursmm.ru/` на ваш домен.

## Как добавить статью

1. Сделайте копию `articles/article-template.html` и назовите файл коротким латинским адресом, например `telegram-content-plan.html`.
2. Замените заголовок, подзаголовок, дату, описание, текст, обложку и JSON-LD внутри страницы.
3. Поменяйте `noindex, nofollow` на `index, follow` и добавьте canonical со ссылкой на статью.
4. Добавьте карточку статьи в `articles/index.html` и адрес новой страницы в `sitemap.xml`.

## Рекомендации для Яндекс.Директ

Используйте в объявлении тот же оффер, что на первом экране: `Пульс ниши для Telegram-канала`. Дополнительным предложением можно оставить бесплатный разбор поста.
